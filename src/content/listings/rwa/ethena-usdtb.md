## Key Features

- **T-Bill Backing** — Each USDtb token is backed by tokenized U.S. Treasury bills, providing a transparent and low-risk collateral base.
- **Stable Peg** — Designed to maintain a 1:1 USD peg through real-world asset reserves rather than algorithmic mechanisms.
- **Ethereum Native** — Operates as an ERC-20 token on Ethereum, making it composable with the broader DeFi ecosystem.
- **Payments & Trading** — Built for practical use cases including on-chain payments, trading collateral, and value storage.
- **Ethena Ecosystem** — Issued under the Ethena umbrella, benefiting from the protocol's existing infrastructure and user base.
- **Transparent Reserves** — Backed by tokenized RWAs with on-chain verifiability of the underlying collateral.
