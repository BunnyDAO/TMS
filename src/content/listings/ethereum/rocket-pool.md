## Getting Started

1. **Stake ETH as a user** — Visit the Rocket Pool app, connect your wallet, and deposit any amount of ETH to receive rETH, a liquid token representing your staked position and accumulated rewards.
2. **Hold or use rETH** — Your rETH balance appreciates in value relative to ETH over time as staking rewards accrue, and it can be used across DeFi protocols.
3. **Become a node operator** — If you want to run a validator, deposit 16 ETH (plus RPL collateral) and set up a Rocket Pool node to earn additional commission on top of standard staking rewards.
4. **Monitor your position** — Track your staking rewards and node performance through the Rocket Pool dashboard or community-built tools.

## Key Features

- **rETH Liquid Staking Token** — Stake ETH and receive rETH, a transferable token that grows in value as staking rewards accumulate, without locking your assets.
- **Reduced Node Operator Requirement** — Validators can be run with just 16 ETH instead of the standard 32 ETH, lowering the barrier for participation.
- **Truly Decentralized Architecture** — Unlike centralized alternatives, Rocket Pool distributes validator duties across a permissionless network of independent node operators.
- **RPL Collateral System** — Node operators stake RPL tokens as collateral, aligning incentives and providing an additional layer of security for the protocol.
- **Non-Custodial** — Users retain control of their assets via smart contracts; no single entity holds staked ETH.
- **DeFi Composability** — rETH is compatible with lending, liquidity, and other DeFi protocols across the Ethereum ecosystem.
