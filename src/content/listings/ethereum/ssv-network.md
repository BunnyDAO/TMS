## Getting Started

1. **Choose your role** — Decide whether you want to participate as a staker delegating validators or as a node operator running SSV infrastructure.
2. **Set up a validator** — Generate or import your Ethereum validator keys and split them using the SSV KeyShares tool to distribute across selected operators.
3. **Select operators** — Browse the operator registry on the SSV Network app and select a set of independent operators to manage your validator.
4. **Fund and activate** — Deposit SSV tokens to cover operator fees, then activate your distributed validator to begin earning staking rewards.

## Key Features

- **Distributed Validator Technology (DVT)** — Splits validator keys into shares across multiple nodes, removing single points of failure and reducing slashing risk.
- **Permissionless operator network** — Anyone can register as an operator and offer validation services to stakers without requiring approval.
- **Fault tolerance** — Validators continue operating even if some nodes go offline, improving uptime and reliability compared to single-node setups.
- **Non-custodial staking** — Stakers retain ownership of their validator keys throughout the process; operators never hold full keys.
- **SSV token payments** — Operators are compensated in SSV tokens, creating an open marketplace for validation services.
- **Protocol integrations** — Designed to work with liquid staking protocols and other Ethereum staking infrastructure as a foundational DVT layer.
