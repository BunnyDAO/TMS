## Getting Started

1. **Choose your role** — Decide whether you are joining as a staker (validator owner) or as a node operator running SSV nodes.
2. **Register as an operator** — If running infrastructure, register your node on the SSV network via the web app and set your operator fee.
3. **Split your validator key** — As a validator owner, use the SSV key-splitting tool to distribute your validator key shares across a set of operators.
4. **Monitor performance** — Track your validator's performance and operator activity through the SSV Explorer dashboard.

## Key Features

- **Distributed Validator Technology (DVT)** — Splits a single validator key into multiple KeyShares distributed across independent operators, removing single points of failure.
- **Non-custodial staking** — Validator owners retain full control of their keys; operators never hold a complete private key.
- **Fault tolerance** — Validators remain active even if some operators go offline, using a threshold signature scheme (BLS).
- **Permissionless operator marketplace** — Anyone can register as an SSV operator and earn fees for running validator infrastructure.
- **Protocol integrations** — Widely integrated with liquid staking protocols and restaking platforms building on Ethereum.
- **Open-source contracts and node software** — All core components are publicly available and audited.
