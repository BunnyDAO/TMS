## Getting Started

1. **Learn about DVT** — Review the Obol documentation to understand how Distributed Validator Technology works and how it improves Ethereum validator resilience.
2. **Set up a Cluster** — Use the Obol SDK or Launchpad to create a distributed validator cluster with multiple participating node operators.
3. **Run Charon** — Deploy Charon, Obol's open-source DVT middleware client, on each participating node to coordinate threshold signing.
4. **Monitor your Validator** — Use Obol's tooling and dashboards to track validator performance and cluster health across all operators.

## Key Features

- **Distributed Validator Technology** — Splits a single Ethereum validator key across multiple operators using threshold cryptography, so no single node can unilaterally sign or cause slashing.
- **Charon Middleware Client** — Open-source client that sits between consensus and execution clients to coordinate distributed signing across cluster participants.
- **Fault Tolerance** — Validators remain active even if a subset of cluster nodes go offline, significantly improving uptime compared to solo staking.
- **Decentralization** — Enables staking pools and institutional operators to distribute trust across multiple independent parties rather than a single entity.
- **Obol SDK & Launchpad** — Developer tooling and a web-based interface for creating and managing distributed validator clusters without deep cryptographic knowledge.
- **Open Source** — All core components are publicly available, auditable, and community-driven under open-source licenses.
