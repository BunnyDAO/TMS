## Getting Started

1. **Explore the documentation** — Visit docs.obol.org to understand DVT concepts and how Obol clusters work.
2. **Set up a cluster** — Use the Obol SDK or Launchpad to create a Distributed Validator cluster with multiple operators.
3. **Configure Charon** — Deploy Charon, Obol's DVT middleware client, on each node participating in the cluster.
4. **Run your validator** — Connect your existing validator client to Charon and begin participating in fault-tolerant Ethereum validation.

## Key Features

- **Distributed Validator Technology (DVT)** — Splits a validator key across multiple nodes so no single machine controls signing, removing single points of failure.
- **Charon Middleware** — Open-source DVT client that coordinates threshold signing among cluster nodes without requiring changes to existing validator clients.
- **Obol Launchpad** — Web-based interface for creating and managing distributed validator clusters with multiple operators.
- **Fault Tolerance** — Clusters continue operating even if a subset of nodes go offline, improving uptime and reducing slashing risk.
- **Decentralized Operator Ecosystem** — The Obol Collective connects solo stakers, node operators, and liquid staking protocols around shared DVT infrastructure.
- **Open Source** — All core components are publicly available, auditable, and community-governed.
