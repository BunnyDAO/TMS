## Getting Started

1. **Connect your wallet** — Visit [balancer.fi](https://balancer.fi/) and connect a compatible Ethereum wallet such as MetaMask or WalletConnect.
2. **Explore pools** — Browse existing liquidity pools to find swap routes or yield opportunities that match your assets.
3. **Add liquidity or swap** — Deposit assets into a pool to earn fees as a liquidity provider, or execute a token swap directly through the interface.
4. **Build on top** — Developers can deploy custom pools using Balancer V3's hooks system and vault architecture by following the official documentation.

## Key Features

- **Flexible Vault Architecture** — Core vault separates accounting and asset management from pool logic, making the system more composable and extensible.
- **Customizable Pool Hooks** — Developers can attach hooks to pools to execute custom logic before or after swaps, joins, and exits.
- **Dynamic Swap Fees** — Pools can adjust swap fees in real time based on on-chain conditions, enabling more sophisticated fee strategies.
- **Weighted & Composable Pools** — Supports multiple pool types including weighted pools, stable pools, and boosted pools for varied liquidity strategies.
- **Permissionless Pool Deployment** — Anyone can create and deploy a new liquidity pool using supported pool factory contracts.
- **Flash Loans** — The vault natively supports flash loans, enabling advanced DeFi strategies without requiring collateral.
