## Getting Started

1. **Explore the docs** — Visit docs.hyperlane.xyz to understand the protocol architecture and supported chains.
2. **Choose your use case** — Decide whether you need token bridging, token issuance, or general interchain messaging for your application.
3. **Deploy the contracts** — Use the Hyperlane CLI to deploy the protocol to any supported chain, or permissionlessly to a new chain.
4. **Build your app** — Integrate the Hyperlane SDK into your frontend or backend to send messages and tokens across chains.

## Key Features

- **Permissionless deployment** — Anyone can deploy Hyperlane to a new blockchain without approval, enabling rapid expansion to new ecosystems.
- **150+ chain support** — Connects a wide range of EVM-compatible chains, rollups, and alternative VMs across 7 different virtual machine environments.
- **Token bridging & issuance** — Supports bridging existing tokens as well as natively issuing new tokens across multiple chains from day one.
- **Interchain messaging** — Send arbitrary data between chains, enabling complex cross-chain application logic beyond simple asset transfers.
- **Modular security** — Customize the trust and security model for your application using configurable interchain security modules (ISMs).
- **Open-source** — Fully open-source codebase available on GitHub, allowing community contributions and independent audits.
