## Getting Started

1. **Explore the network** — Visit [axelar.network](https://axelar.network) to understand the supported chains and available cross-chain routes.
2. **Review the documentation** — Head to [docs.axelar.dev](https://docs.axelar.dev) to find developer guides, SDK references, and integration tutorials.
3. **Integrate the SDK** — Use the AxelarJS SDK or General Message Passing (GMP) API to add cross-chain functionality to your dApp.
4. **Deploy and test** — Connect to the Axelar testnet to validate your cross-chain calls before going live on mainnet.

## Key Features

- **General Message Passing (GMP)** — Send arbitrary data and tokens across chains with a single smart contract call, enabling complex cross-chain logic.
- **Cross-Chain Token Transfers** — Move assets between any connected blockchain with built-in security guarantees from Axelar's validator set.
- **Decentralized Validator Network** — Security is provided by a permissionless proof-of-stake network of validators, avoiding centralized relay risks.
- **Multi-Chain Support** — Connects EVM chains, Cosmos chains, and other ecosystems under a unified interoperability layer.
- **Axelar Virtual Machine (AVM)** — Enables developers to write cross-chain programs that execute logic across multiple blockchains natively.
- **One-Click UX** — Abstracts chain complexity so end users can interact with any supported chain from a single interface.
