## Getting Started

1. **Explore the network** — Visit axelar.network to understand supported chains and available cross-chain routes.
2. **Integrate the SDK** — Use the Axelar SDK or AxelarJS to add cross-chain functionality to your dApp.
3. **Send a cross-chain message or transfer** — Use the General Message Passing (GMP) API to call contracts on remote chains or move tokens across networks.
4. **Monitor transactions** — Track cross-chain activity and transaction status via Axelarscan, the network explorer.

## Key Features

- **General Message Passing (GMP)** — Send arbitrary data and contract calls across blockchains with a single transaction
- **Cross-Chain Token Transfers** — Move native and wrapped tokens between supported chains securely
- **Decentralized Validator Network** — Backed by a proof-of-stake validator set that secures cross-chain communication
- **Broad Chain Support** — Connects EVM chains, Cosmos ecosystem chains, and other Layer 1 and Layer 2 networks
- **Interchain Token Service** — Deploy and manage tokens natively across multiple chains from a single interface
- **Developer SDK & APIs** — Provides AxelarJS SDK, smart contract interfaces, and REST APIs for straightforward integration
