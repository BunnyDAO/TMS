## Getting Started

1. **Connect your wallet** — Visit fragmetric.xyz and connect a Solana-compatible wallet such as Phantom or Backpack.
2. **Deposit LSTs** — Deposit supported liquid staking tokens into the protocol using the Normalized Token Program interface.
3. **Restake assets** — Your deposited assets are automatically allocated across Node Consensus Networks (NCNs) to earn restaking rewards.
4. **Track rewards** — Monitor your earned NCN rewards and staking positions directly through the Fragmetric dashboard.

## Key Features

- **NCN Reward Distribution** — Fairly distributes rewards from Node Consensus Networks to participants using on-chain token extension logic.
- **Normalized Token Program** — Standardizes multiple LSTs into a unified interface, enabling efficient and composable restaking across Solana.
- **Multi-LST Support** — Accepts a variety of Solana liquid staking tokens, broadening access and flexibility for restakers.
- **Economic Security** — Strengthens the Solana ecosystem by extending staked capital to secure additional network services and protocols.
- **Token Extensions** — Leverages Solana's native token extension standard for transparent and programmable reward mechanics.
