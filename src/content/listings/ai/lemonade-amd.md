## Getting Started

1. **Install Lemonade** — Download and install the Lemonade server from the official website or AMD's GitHub repository.
2. **Configure your hardware** — Lemonade will detect your available AMD GPU or NPU and configure inference accordingly.
3. **Load a model** — Select and load a supported LLM for text, image, or speech tasks through the server interface.
4. **Send requests** — Query the local server via its API to run inference entirely on your own machine.

## Key Features

- **GPU & NPU acceleration** — Leverages both AMD GPUs and NPUs to maximize local inference performance
- **Multi-modal support** — Handles text, image, and speech inference from a single local server
- **Privacy-first** — All inference runs locally with no data sent to external servers
- **Open-source** — Fully open-source and developed by AMD, allowing community contributions and transparency
- **LLM server API** — Exposes a standard server interface for easy integration with existing tools and workflows
- **AMD hardware optimized** — Purpose-built to get the most out of AMD's AI-capable hardware lineup
