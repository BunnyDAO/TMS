## Getting Started

1. **Browse the repository** — Visit the GitHub repo and explore the directory structure, which organizes prompts by tool name.
2. **Find a tool** — Look for the AI coding tool you're interested in (e.g., Cursor, Claude Code, Windsurf) and open its corresponding file.
3. **Study the prompt** — Read the extracted system prompt to understand how that tool instructs its underlying model.
4. **Contribute or follow updates** — Star the repo to track new additions; new prompts are regularly added as tools are updated or released.

## Key Features

- **20+ tools covered** — Includes system prompts from Claude Code, Cursor, Windsurf, Devin, Replit, Lovable, v0, Perplexity, and many more
- **Research transparency** — Exposes the hidden instructions behind commercial AI agents, enabling independent study of prompt design choices
- **Prompt engineering reference** — Useful for developers building their own AI agents who want to learn from production-grade system prompts
- **Actively maintained** — The collection is regularly updated to reflect changes in tools and to add newly extracted prompts
- **Community-driven** — Open issues welcome contributions, corrections, and requests for additional tools
