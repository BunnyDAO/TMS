## Getting Started

1. **Clone the repo** — `git clone https://github.com/nexu-io/html-anything` and navigate into the project directory
2. **Ensure a supported agent CLI is on your PATH** — html-anything auto-detects Claude Code, Cursor Agent, Codex, Gemini CLI, GitHub Copilot CLI, OpenCode, Qwen Coder, or Aider
3. **Open the editor** — launch the local app and select a surface type and skill template to start generating HTML
4. **Export your output** — use one-click export to share to WeChat, X, or Zhihu, or download as `.html` or `.png`

## Key Features

- **8 Agent CLIs Supported** — auto-detects Claude Code, Cursor, Codex, Gemini CLI, Copilot CLI, OpenCode, Qwen Coder, and Aider from your PATH with no extra configuration
- **9 Deliverable Surface Types** — generate magazine articles, keynote decks, résumés, posters, tweet cards, web prototypes, data reports, Xiaohongshu cards, and Hyperframes videos
- **75 Composable Skill Templates** — a broad library of templates covering common content and layout patterns across all surface types
- **Sandboxed Preview** — view generated HTML in an isolated preview environment before exporting
- **One-Click Export** — publish directly to WeChat, X, or Zhihu, or download as a standalone `.html` or `.png` file
- **No API Key Required** — reuses the authenticated CLI session you already have, keeping your workflow local-first and private
