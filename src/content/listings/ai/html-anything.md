## Getting Started

1. **Clone the repository** — Run `git clone https://github.com/nexu-io/html-anything` and navigate into the project directory.
2. **Ensure a supported agent is on your PATH** — HTML Anything auto-detects Claude Code, Cursor Agent, Codex, Gemini CLI, GitHub Copilot CLI, OpenCode, Qwen Coder, or Aider. No API key setup needed if you're already logged in.
3. **Choose a skill template** — Pick from 75 composable skill templates across surfaces like magazine articles, résumés, keynote decks, posters, or tweet cards.
4. **Generate and export** — Let the agent write your HTML, then export directly to WeChat, X, or Zhihu, or download as `.html` or `.png`.

## Key Features

- **Zero API Key Required** — Reuses the CLI session you already have authenticated, so no additional credentials or billing setup is needed.
- **8 Coding Agents Supported** — Auto-detects Claude Code, Cursor Agent, Codex, Gemini CLI, GitHub Copilot CLI, OpenCode, Qwen Coder, and Aider from your system PATH.
- **75 Skill Templates** — Composable templates cover a wide range of document and content generation tasks out of the box.
- **9 Deliverable Surfaces** — Supports magazine articles, keynote decks, résumés, posters, Xiaohongshu cards, tweet cards, web prototypes, data reports, and Hyperframes videos.
- **One-Click Export** — Publish directly to WeChat, X, or Zhihu, or download finished output as `.html` or `.png`.
- **Local-First Architecture** — All generation runs through your local agent session, keeping data off third-party servers.
