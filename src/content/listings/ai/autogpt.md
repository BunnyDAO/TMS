## Getting Started

1. **Install prerequisites** — Ensure you have Docker Engine 20.10+, Docker Compose 2.0+, Git, Node.js 16+, and npm 8+ installed on your system.
2. **Run the setup script** — On macOS/Linux, run `curl -fsSL https://setup.agpt.co/install.sh -o install.sh && bash install.sh` to set up the platform automatically.
3. **Configure your environment** — Add your LLM API keys and adjust settings via the provided configuration files or the platform UI.
4. **Build and deploy agents** — Use the visual interface to compose agent workflows and deploy them to run autonomously on your local or cloud infrastructure.
